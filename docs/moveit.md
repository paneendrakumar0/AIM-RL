# MoveIt

`aim_arm_moveit_config` is a scaffold package that defines:

- `arm` planning group from `base_link` to `tool0`.
- Home and ready named states.
- KDL kinematics settings.
- Joint limits matching the URDF.

MoveIt 2 is not installed on this machine yet. After optional dependencies are installed, this package should be expanded with generated planning pipelines, controllers, and RViz MoveIt config.
